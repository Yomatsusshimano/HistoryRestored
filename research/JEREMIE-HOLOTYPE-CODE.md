Blank catalog metadata does not demonstrate that an original label or notebook lacks the notation.

The original code key is still required. None of its numbers has been converted to depth, elevation, a bag number or a layer. UF73946 is also distinct from dated UF74968 and UF74978, despite shared taxon and collection date. No age or sediment-unit assignment passes between those accessions. Rounded type-locality coordinates differ from catalog coordinates; their reference systems and precision remain insufficient for interpreting geographic change.
