2026-10-09. C005/S325/S327; selected primary-record audit without independent review.

The [direct-date calculation](NOMLAKI-ISOCHRON-CHECK.md) does not by itself identify every regional ash. This follow-up inspects S325TableA1, printed350/PDF16, and the original S327TableS4workbook's group heading and FLV-119-WW row. It preserves source-specific sample labels instead of treating a similar name or composition as an authenticated age transfer.

## FLV-119-WW is a fraction-specific lead

S327TableS4row311 begins group22, labelled Tuff of Danville, with the age label approximately4.8Ma(4.37Ma). Row316 within that group identifies analysis2199, sample **FLV-119-WW LT. COL. GLS. T183-**, analyzed1989-01-25. Its raw21cells and the heading are preserved in the [structured crosswalk](../data/nomlaki-chemical-crosswalk.json). The group label is a correlation assignment; it is not a direct date of this Willow Wash sample. The two ages in the heading are retained without choosing one here.

This is a useful later identification lead for the [1991ambiguity](WILLOW-WASH-NOMLAKI.md), which reported FLV-119-WW as bimodal. The light-coloured glass fraction appears in the later Danville group. That does not establish that every shard, the whole bed, or the other named candidate FLV-117-WW belongs to Danville. The fraction's numerical record also does not resolve which layer was used in the2008Willow Wash age extrapolation.

The same analysis appears in S327TableS2row329; repetition inside the same study is not independent evidence. Its coordinate cells use missing-value markers, so no new position is assigned. No direct ROSER-to-Mohave chemical comparison or acceptance threshold is claimed from this row.

## Lower Nomlaki CaO: preserve the conflicting statements

S325printed351says that JRK-DV-39 has lower CaO than jf-01-07, CWAJB02 and CAES#1-1143, and similarly describes Topock#1as lower. The visually inspected TableA1on printed350instead reports:

| Printed sample label | Number of analyzed shards | CaO,wt% |
| --- | ---: | ---: |
| Topock#1 |19 |0.938 |
| CWAJB02-1 |19 |0.914 |
| jf-01-07 |15 |0.904 |
| CAES#1-1143 |15 |0.923 |
| JRK-DV-39 |22 |0.956 |

Both named values are higher than each of the three comparison values as printed. This is an internal prose-table discrepancy. The labels and numbers are transcribed rather than corrected. The reported analytical totals differ; no normalization, inferred standard error or statistical separation is substituted for the source. Number of shards is not a number of independently dated eruptions.

The source acknowledges possible multiple similar lower-Nomlaki layers while provisionally adopting a single-layer correlation. The CaO discrepancy alone neither proves multiple eruptions nor invalidates all correlations. Resolving it requires original shard-level values, analytical calibration and any correction to the prose or table. An unexplained inconsistency does not establish deliberate fabrication or a historical event date.
