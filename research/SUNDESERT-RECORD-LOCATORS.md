## What this changes

The bibliography distinguishes a general dating appendix from the Parker Valley site report cited by S203. Both are retrieval targets; neither has yet been demonstrated to contain the unresolved9.6 Ma basalt analysis. This prevents treating every Fugro1975 citation as the same document.

The paleomagnetic summary assigns older fluvial deposits to a pre-Brunhes interval using reversed polarity and a then-used700,000-year boundary. That is an interpretation reported by the bibliography, not a direct radiometric measurement, current calibrated boundary, or verified Bouse-bed age. Original demagnetization results, polarity stability, depositional context and correlation are required before using it as a chronological constraint. This source does not establish a common event with the dated tuff or historical maps.
